# MLLM Gallery

A local React + Vite landing page for an English MLLM architecture gallery.

## Stack

- React 19
- Vite 5
- `motion`
- `lucide-react`
- Plain CSS
- Inter from Google Fonts

## Run Locally

```powershell
npm install
npm run dev
```

The app is configured for:

```text
http://localhost:4173
```

## Build

```powershell
npm run build
```
